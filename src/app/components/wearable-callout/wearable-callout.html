App companion para Wear OS

Las lecturas de este panel llegan desde un reloj con Wear OS que envía la frecuencia cardiaca al backend. El proyecto del reloj vive en un repositorio aparte.

Instalación desde el código fuente:

  1. Clona el repositorio: git clone {{ repoUrl }}.git
  2. Ábrelo en Android Studio y espera a que sincronice Gradle.
  3. Con el reloj o el emulador conectado, ejecuta ./gradlew installDebug
